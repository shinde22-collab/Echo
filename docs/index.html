THE SURROGATE
The experiment, precisely +

UCI Banknote Authentication: 1,372 rows, four wavelet features. Remove 24 identical feature rows before a stratified split: 500 victim-training rows, 578 query-pool rows, 270 test rows. Split and victim seed: 42. Acquisition seeds: 7, 19, 42, 73, 101. Budgets: 25, 50, 100, 150, 250, 500.

Fit feature scaling on unlabeled pool inputs only. Use a 160-tree Random Forest as the victim and an RBF SVC with C=10 and gamma=scale as the surrogate. Acquire at most 25 rows per batch. Each strategy follows a nested sequence, so 500 queries covers all six checkpoints in one run. The test set never guides acquisition or model selection.

What the numbers mean +

Fidelity is agreement with the hidden model; accuracy is agreement with dataset labels. They answer different questions. The curve’s band shows one sample standard deviation over acquisition seeds, with the victim and data split fixed. It is not a confidence interval and does not measure variation across datasets or victim models.

The hosted observatory replays precomputed experiments and runs surrogate inference locally. The optional Python API serves live, budgeted victim queries. The visual decision map is a two-dimensional slice, not a full four-dimensional fidelity estimate. More queries do not guarantee a monotonic improvement.

Why this matters +

Prediction-only access can reveal a surprising amount about a model’s behavior. This controlled study illustrates model extraction, surrogate learning, and an ML security risk on a small public dataset. Agreement here does not imply recovery of architecture, weights, or training data, and does not predict performance against production systems.

Research context: Tramèr et al., Stealing Machine Learning Models via Prediction APIs (USENIX Security 2016) ↗.
